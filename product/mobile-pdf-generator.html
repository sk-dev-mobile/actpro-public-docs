PDF генератор: DTO и HTML

Две точки, если мобильный клиент хочет совпасть с тем, что уходит в печать на сервере.

1. Актуальный DTO для генератора

В монорепозитории продукта (ветка main):

  • JSON Schema: packages/act-render/schema/act-render-dto.schema.json
  • Текст по полям: docs/mobile/act-render-dto.md
  • Pydantic-модели: apps/backend/app/modules/acts/render/schemas.py
  • Сборка из сохранённого акта: apps/backend/app/modules/acts/render/mapper.py

Схема в репо, не на этом портале. Если доступа к git нет, попросите у команды выгрузку этих файлов.

2. HTML шаблон генератора

Шаблоны, стили и шрифты общие у сервера и телефона: пакет packages/act-render/ в том же репозитории.

  • Шаблоны Mustache: act-render-bundle/templates/ (acceptance.mustache, expertise.mustache, общие куски в partials/)
  • Стили: act-render-bundle/styles/ (common.css плюс стили варианта)
  • Шрифты и параметры страницы: act-render-bundle/manifest.json

Как собирать HTML из пакета и с какими эталонами сверяться: packages/act-render/README.md. Свежий пакет можно получить без релиза приложения: GET /api/v1/render-bundle?schema_version=2.
